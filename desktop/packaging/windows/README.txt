LiteTunnel @VERSION@ для Windows (x64)

Запуск
  Распакуйте архив в любую папку, например C:\Users\<имя>\LiteTunnel, и запустите LiteTunnel.exe.
  Программа не подписана: если Windows покажет «Система Windows защитила ваш компьютер»,
  нажмите «Подробнее» → «Выполнить в любом случае».
  Ссылки litetunnel:// из браузера открываются в приложении после первого запуска.

Режимы
  Системный прокси: работает без прав администратора. При выходе и после сбоя
  настройки прокси возвращаются как были.
  VPN (TUN): весь трафик, нужны права администратора. При подключении Windows спросит
  разрешение, и приложение перезапустится от имени администратора.

  Закрытое окно при активном подключении уходит в трей (значок у часов); «Выход» в меню значка.

Данные: %LOCALAPPDATA%\LiteTunnel. Удаление: закройте приложение и удалите папку с ним.
